# What's new

[Русский](CHANGELOG.md)

## 1.5

- New Where the day went tile: time per program for today, with real names and icons. Off by default.
- Fill theme: the Now playing tile now fills to its full height as the track progresses.

## 1.4

- New Now playing tile: music and video from browsers and media players, with cover art, track progress and the buttons the source allows. Off by default.
- An enabled tile is always visible: while there is no data it shows its name and a hint.
- The update bar is now yellow and sits above the tiles.

## 1.3.3

- Installing, updating and removing now show windows: what will happen, the progress and the result.
- A new version is announced by a blue bar below the tiles. Fixed: the update question could hide behind other windows.
- The widget no longer turns into a column at the screen edge: only you choose the mode. It snaps to screen edges, center lines and window edges.
- Hover cards are turned off for now.

## 1.3.2

- Simpler hover cards: no gridlines, axis labels or extra rows.

## 1.3.1

- Fixed: in the Fill theme the memory and Claude limit levels showed as a narrow column instead of spanning the tile.

## 1.3

- New themes Oscilloscope, Blueprint and Pixels; the dark LCD variant is now olive.
- Clock and calendar: several faces matching each theme. The flip clock was replaced by plain digits.
- Weather: an animated tile background (can be turned off).
- Hover detail cards for all tiles.
- Game summary: a card with FPS, 1% low, stutters, temperatures and energy after a session.
- Optional: per-thread CPU bars, a memory map by process, a GPU fan icon.
- Thin tiles; settings grouped, game mode moved to its own tab.
- Fixes: the widget can be pulled away from the screen edge; half-width tiles show their values properly.

## 1.2

- Game mode: FPS, 1% low and frame time over a windowed or borderless game (Ctrl+Shift+F).
- Detailed hover charts for CPU, GPU, memory, network and energy tiles.
- Energy tile: CPU and GPU consumption per day and month, cost at your tariff.
- Focus tile: a pomodoro timer.
- LCD theme.
- Appearance profiles: up to six, transferable as a file.
- Fixes: a tile's own color applies at warm temperatures too; the crest line was removed from Fill charts.

## 1.1

- The downloaded `widget.exe` installs itself when run and adds a Start menu shortcut.
- The widget checks GitHub for new versions and offers to update.
- Running it again brings up the already running widget.

## 1.0

- First release: CPU, GPU, memory, network, disks and processes; three themes, five modes.
